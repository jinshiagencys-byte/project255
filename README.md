# DocCare - Doctor Appointment & Health Booking App

A modern, native Android application built with **Kotlin** and **Jetpack Compose**, rewritten from project assets to provide a comprehensive healthcare specialist discovery and appointment booking experience.

## Features

- **Doctor Specialties & Categories**: Browse verified medical departments including Cardiology, Dentistry, Neurology, Orthopedics, and Radiology.
- **Top Specialist Directory**: Discover board-certified doctors with photos, ratings, patient counts, clinic locations, and experience details.
- **Doctor Profile & Quick Actions**:
  - Direct telephone dialer integration
  - Interactive doctor messaging
  - Turn-by-turn map directions to clinic addresses
  - External hospital and practice websites
- **Appointment Scheduling**:
  - In-person clinic visit or HD video consultation options
  - Calendar date selector and time slot picking
  - Patient condition notes
- **My Appointments**:
  - Filter by Upcoming, Completed, and Cancelled
  - Reschedule and cancel appointment workflows
- **Interactive Doctor Chat**:
  - Chat with specialists with instant responsive medical guidance
- **Patient Profile**:
  - Patient health metrics (Blood group, weight, height)
  - Saved favorite doctors
  - Medical history records & emergency contacts
- **Modern Material Design 3**:
  - Clean medical aesthetic, dynamic color system, adaptive layouts
  - Custom adaptive launcher icon

## Technology Stack

- **Platform**: Android (minSdk 26, targetSdk 36)
- **Language**: Kotlin 2.2.10
- **UI Framework**: Jetpack Compose with Material Design 3
- **Architecture**: MVVM with Kotlin Coroutines & StateFlow
- **Image Loading**: Coil Compose
- **Serialization**: Kotlinx Serialization JSON
- **Build System**: Gradle 9.3.1 with Android Gradle Plugin (AGP) 9.1.1
